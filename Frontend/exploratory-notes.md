## Charter
Explore VALR as a first-time crypto user and evaluate usability, clarity, and potential risks.

## Timeboxed
Start: 16:00  
End: 16:45  

## Areas Covered
- Landing page
- Registration
- Login
- BTCZAR trading page
- Markets overview

## Observations

### Landing Page
- Clean UI, but crypto terminology may confuse beginners
- CTA's are clear ("Sign Up"), ("Log in")

### Registration
- Password requirements not clearly communicated upfront
- Error messages are reactive instead of proactive

### Login
- Standard flow, no major issues
- No visible brute-force protection indicators

### Trading Page
- Data-rich but overwhelming for new users
- No onboarding guidance/tooltips
- Price updates appear real-time (good)

### Markets Page
- Easy to scan
- Lacks filtering/sorting options (usability gap)

## Risks Identified

1. Trading interface complexity
   - High cognitive load
   - Risk: user mistakes or abandonment

2. Registration UX
   - Reactive validation
   - Risk: user drop-off
